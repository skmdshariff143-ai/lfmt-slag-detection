# Experimental signal baselines (v2.2)

These additions are isolated from the default five-method classical pipeline.
No new package is required. Enable all three with `--extended-model` in the
standard conference harness. All eight methods receive identical thermograms,
ground truth is used only for evaluation, and the same detector is used for all.
The Tier 1 morphology correction remains a proposal, so this experiment measures
processing changes without simultaneously changing segmentation policy.

- **Temporal Pixel Net:** NumPy equivalent of a small two-layer 1×1 CNN, with
  eight baseline-subtracted temporal channels plus their fixed 3×3 averages.
  Sixteen tanh hidden units and a logistic pixel output; balanced binary loss.
  Training uses ten synthetic specimens generated by the existing FEM solver,
  including two healthy controls, with clean/30/20 dB AWGN variants. Three
  separate geometries are used only for validation, including a healthy case.
  No conference-grid geometry, coordinate feature, or test mask is used to fit
  the model. This is a small feasibility baseline, not a validated U-Net.
- **TSR:** Degree-four polynomial fit of log positive temperature rise against
  log time since heating ended. Uses only cooling frames, excludes nonpositive
  pixels, and returns spatial deviation of the first logarithmic derivative.
  This is empirical TSR after finite-duration chirp heating, not an assumed
  ideal flash-pulse depth inversion. Acquisition must include cooling.
- **Chirp Phase Fusion:** Detrended, Hann-windowed Fourier coefficients at
  resolvable frequencies inside the chirp sweep, phase referenced to the drive.
  Exports per-band phases and fuses circular distance from spatial background,
  weighted by response magnitude. Unsupported/zero-energy bands have no weight.
  These are transient transfer phases, not steady-state lock-in measurements.

Reproduction (run with `src` installed or on PYTHONPATH):

```powershell
$env:OPENBLAS_NUM_THREADS='1'
$env:OMP_NUM_THREADS='1'
python scripts/train_segmentation_baseline.py
python scripts/run_conference_study.py --conference --config configs/conference_v2_experimental.yaml --extended-model results/conference/analysis/tier2/temporal_pixel_v1.json --outdir results/conference/analysis/tier2/benchmark_v2_2
```

Training report and JSON weights include a checkpoint hash and full per-case
configuration. Validation reports raw probability masks at a fixed 0.5 cutoff;
conference evaluation applies the common Otsu detector instead. Keep these
metrics separate. The benchmark manifest records the checkpoint hash and new
pipeline version. Existing benchmark output directories cannot be overwritten,
the frozen conference directory is rejected, and new caches require matching
configuration hashes.

The acquisition is 14 seconds with four seconds of cooling. Camera sampling is
32×32 at 10 Hz and the FEM grid is 30×22×12: small-defect resolution remains a
limitation. Improvements must be evaluated against classical methods re-run in
this same version, not attributed to processing by comparison with old figures
using different grids/noise behavior. Training AWGN is narrower than the full
benchmark noise model; no experimental generalization is established.

The initial held-out run demonstrates a noise failure: at 20 dB the two defect
specimens have IoU about 0.0048 and 0.0519, and the healthy specimen has 18.46%
foreground pixels at the fixed 0.5 cutoff. Clean defect IoUs are 0.8333 and 0.65.
These are only two defect geometries and one healthy control, not evidence of
general performance. See `training_report.json` for all nine condition-level
results, rather than reporting the clean figures alone.

## Full-grid result

The separately generated v2.2 run contains 6,448 evaluations: eight methods on
806 identical inputs (775 defect and 31 healthy inputs per method). Defect
detection fractions are Temporal Pixel Net 47.1%, Matched Filter 35.1%, SPCT
27.4%, RPT 24.8%, PCT 24.3%, Chirp Phase Fusion 21.0%, TSR 2.6%, and Raw Contrast
1.3%. The learned method flags **29/31 healthy inputs**, so its increased
sensitivity cannot be described as better usable detection. Threshold calibration
and evaluation at matched false-alarm rates are still required. These results do
not replace or directly replicate the frozen historical benchmark.
