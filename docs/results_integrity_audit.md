## 1. Executive Summary

This document presents the comprehensive results integrity audit of the Linear Frequency-Modulated Infrared Thermography (LFMT) numerical benchmark framework. The investigation audited all simulation equations, blind signal processing pipelines, metric definitions, statistical aggregations, and physical property propagation across the full 4,030-evaluation conference study.

All identified ambiguities and anomalies have been resolved from first principles. The resulting benchmark dataset is frozen in `results/conference/final/` and verified with automated audit scripts (`scripts/audit_conference_results.py`, `scripts/validate_experiment_results.py`, `tests/test_audit_integrity.py`).

## 2. Issues Investigated, Root Causes & Mathematical Corrections

### 2.1 Anomaly in Clean PCT Localization Error
- **Issue Investigated:** Under clean (noise-free) conditions, initial runs reported $0.00\text{ mm}$ localization error despite low segmentation IoU.
- **Root Cause:** When an unperturbed clean background exhibited near-zero EOF contrast, the segmentation detector found no contour above threshold. The default fallback centroid was $(50.0, 35.0)\text{ mm}$, which coincidentally matched the exact plate center and ground-truth defect center $(x=50, y=35)\text{ mm}$.
- **Mathematical Correction:**
  1. Updated `DefectDetector` and `compute_metrics` so that if no defect candidate is isolated, `centroid_mm` and `localization_error` strictly return `NaN`.
  2. Enhanced `PrincipalComponentThermography` to select EOF modes using spatial excess kurtosis $\kappa = |\mu_4/\sigma^4 - 3|$ on normalized components, ensuring stable mode selection under clean and noisy regimes alike.

### 2.2 Detected-Only vs. All-Candidate Localization Metrics
- **Issue Investigated:** Reporting a single localization error conflated runs where no defect was found with runs where a defect was successfully localized.
- **Root Cause:** Without separation, averages over undetected runs either penalized methods unfairly or masked localization precision.
- **Mathematical Correction:**
  - Introduced `loc_error_detected_mm`: Evaluated strictly on confirmed true-positive detections ($E_{\mathrm{loc}}$ where $\mathrm{is\_detected} == \mathrm{True}$).
  - Introduced `loc_error_all_mm`: Evaluated on any candidate contour generated by the blind detector.
  - Undetected runs return `NaN`, ensuring clean separation in statistical aggregations without artificial zero-padding.

### 2.3 Healthy Control Specimen Independent Specificity Logic
- **Issue Investigated:** Need to ensure healthy controls ($D = 0\text{ mm}$) evaluate false alarms independently without ground-truth contamination.
- **Root Cause:** Healthy specimens have no ground truth inclusion ($gt\_sum = 0$).
- **Mathematical Correction:**
  - On healthy specimens, `is_detected` is strictly `False`.
  - `is_false_positive` is defined independently as `candidate_detected` (whether the blind detector flagged an anomaly on a defect-free plate).
  - Specificity is computed as $\mathrm{Specificity} = 1.0 - \mathrm{Mean}(\mathrm{is\_false\_positive})$.

### 2.4 Physical Sensitivity Propagation & Configuration Invalidation
- **Issue Investigated:** Sensitivity study variations for material properties ($k_{\mathrm{slag}}, C_{p,\mathrm{slag}}, h_{\mathrm{conv}}$) were previously constrained to baseline values in the FEM forward assembly.
- **Root Cause:** `PlateConfig` and `InclusionConfig` lacked explicit per-run overrides for thermal conductivity, density, and specific heat, so parameter sweeps defaulted to database constants.
- **Mathematical Correction:**
  - Added property override fields to `PlateConfig` and `InclusionConfig` in `src/lfmt/config.py`.
  - Connected overrides directly to the 3D weak variational stiffness matrix $\mathbf{K}$ and mass matrix $\mathbf{M}$ in `src/lfmt/simulation/fem.py`.
  - Updated `compute_config_hash` in `scripts/run_conference_study.py` to include all physical PDE parameters ($k, \rho, C_p, h_{\mathrm{conv}}, q_0$).

### 2.5 Clarification of Thermal Terminology
- **Issue Investigated:** The parameter $\approx 6.915\text{ K}$ was previously labeled ambiguously as "peak contrast".
- **Physical Reality:**
  - **Peak Surface Temperature Rise above Ambient:** $\Delta T_{\mathrm{surf,max}} = \max(T_{\mathrm{surface}}(t) - T_{\mathrm{amb}}) \approx 6.915\text{ K}$.
  - **Peak Defect Thermal Contrast:** $\Delta T_{\mathrm{defect,max}} = \max |T_{\mathrm{defect}}(t) - T_{\mathrm{sound}}(t)| \approx 0.6151\text{ K}$ (for $D=8\text{ mm}, z=0.4\text{ mm}$).
  - Standardized terminology across all tables, scripts, figures, and documentation.
